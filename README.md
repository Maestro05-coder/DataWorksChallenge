# ExxonMobil DataWorks Challenge 2026

## About the Challenge

> **Topic:** Machine Learning-Assisted History Matching and the Challenge of Production Forecasting

---

## Files

**The dataset consists of several Excel files:**

- `01 Introduction` — Information about nomenclature and uncertainty values
- `02 Field Production` — Historical production of the field
- `03 Train Cases 1` — Dataset used to train model robustness (part 1)
- `04 Train Cases 2` — Dataset used to train model robustness (part 2)
- `05 Train Cases 3` — Dataset used to train model robustness (part 3)
- `06 Train Cases 4` — Dataset used to train model robustness (part 4)
- `07 Validation Cases` — Dataset used to evaluate machine learning model performance
- `08 Test Cases` — Dataset used to train model robustness
- `09 Template Deliverable` — Empty template for populating your model results

## Submission Requirements

### 1. Source code and model files

Include the source code, machine learning models, and other files used for development, analytics, and testing. Zip them into one folder named `{team_name}.zip`.

### 2. Documentation (PowerPoint)

Suggested topics include:

- Executive overview
- Background and context
- Study objectives
- Methodological approach
- Key findings and results
- Conclusions

### 3. Power BI dashboard

- Use the Excel output from your model (`09 Template Deliverable.xlsx`) as the dashboard source.
- Use Power BI version 2.154.1260.0 (64-bit, May 2026) or earlier.
- Create charts that clearly visualize your model output.

### 4. Seven-minute video

- Upload your video to YouTube as public or unlisted. Ensure it is accessible and not private.
- Add the YouTube link to a Notepad file and upload that file to the website. Do NOT upload the `.mp4` video file to the website.
- You may use your documentation slides (submission item 2) as a guide.
- Suggested topics include:
  - Project background
  - Your approach
  - Results
  - Insights
  - Collaboration
  - Next steps
